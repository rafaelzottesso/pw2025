Sobre o sistema

Este sistema foi desenvolvido para gerenciar as solicitações acadêmicas dentro do IFPR, oferecendo uma interface segura e eficiente tanto para alunos quanto para servidores. Através dele, é possível criar solicitações, acompanhar o andamento e visualizar o histórico completo.
