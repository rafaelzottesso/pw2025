A disciplina

A disciplina de Programação para Web tem como objetivo apresentar os conceitos fundamentais de desenvolvimento web, abrangendo tanto o front-end quanto o back-end. Os alunos aprenderão a criar páginas web dinâmicas e interativas, utilizando tecnologias como HTML, CSS, JavaScript e frameworks populares. Além disso, serão introduzidos aos princípios de design responsivo e acessibilidade, visando garantir que as aplicações sejam funcionais e agradáveis em diferentes dispositivos e para todos os usuários.


🧾 Sobre o Sistema de Gerenciamento de Solicitações Acadêmicas

Nosso sistema foi desenvolvido com o objetivo de facilitar e organizar o processo de gerenciamento de solicitações acadêmicas dentro de instituições de ensino. A plataforma permite que alunos e servidores façam, acompanhem e gerenciem diferentes tipos de solicitações de maneira centralizada, transparente e eficiente.

Através de um ambiente seguro e controlado, o sistema conta com funcionalidades que incluem:

  • Cadastro e gerenciamento de Campi e Cursos, permitindo a associação entre unidades e áreas acadêmicas.
  • Registro de Alunos e Servidores, com vinculação direta aos usuários do sistema para acesso personalizado.
  • Criação de Tipos de Solicitação, com definição de prazos internos e externos, garantindo previsibilidade e clareza no atendimento.
  • Abertura de Solicitações, nas quais os usuários informam a turma, justificativa e tipo de demanda.
  • Acompanhamento por Status, com um histórico detalhado de cada solicitação, tornando o processo auditável e rastreável.
  • Fluxo baseado em permissões, onde apenas determinados status permitem a edição de uma solicitação, assegurando integridade dos dados.

A proposta é proporcionar uma experiência intuitiva e eficiente, tanto para quem solicita quanto para quem atende, reduzindo burocracias e promovendo a agilidade na resposta às demandas acadêmicas.

🧩 Sobre o Diagrama de Classes

O diagrama de classes apresentado foi gerado com base nos modelos definidos no backend do sistema, desenvolvido em Django (framework web em Python). Para criar o diagrama visual, utilizamos a biblioteca Graphviz, que permite representar graficamente estruturas de dados por meio de nós e relacionamentos.

O código Python foi escrito para interpretar os relacionamentos entre os modelos — como chaves estrangeiras (ForeignKey) e vínculos com usuários — e gerar automaticamente a estrutura do diagrama. O resultado é uma representação clara da arquitetura de dados, facilitando tanto a documentação quanto o entendimento do sistema.
